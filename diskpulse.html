What Makes DiskPulse Indispensable

01 · TELEMETRY ⚡️

Real-Time Velocity & Burn Forecast

Standard tools only show static bytes. DiskPulse tracks the burn velocity in GB/hour and forecasts exactly when Xcode or agent tasks will exhaust your SSD before compilation crashes.

Velocity Rate +4.3 GB / hour
Crash Forecast 42 minutes remaining
02 · AI AGENTS 🛡️

PreToolUse Guard for AI Agents

Cleaning cannot outrun 3 parallel agent compiler tasks. The PreToolUse hook intercepts heavy bash commands before disk hits 0 GB, pausing builds until space is reclaimed.

$ claude code → bash [xcodebuild]
[guard] Refused: Free space < 5 GB (4.8 GB)
[auto-clean] Reclaimed 9.2 GB → Running build
03 · KERNEL 🧠

Swap & Memory Pressure Relief

macOS swap lives on your SSD. A full disk causes macOS to force-quit apps. DiskPulse frees disk space under memory pressure and gently sends SIGTERM to dead orphan language/MCP servers.

Swap File Condition 1.6 GB (Encrypted)
Dead LSP / MCP Servers 1 terminated (gentle SIGTERM)
04 · INTEGRITY 🔒

Strict Zero-Harm Allow-List

Cleans only files that safely rebuild themselves. Open applications are never quit. Uncommitted git work, user documents, and active agent sessions are strictly untouchable.

Git Uncommitted Work Strictly untouchable
Running Apps Never quit
