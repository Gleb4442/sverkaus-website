DiskPulse

Конфиденциальность

Коротко: DiskPulse никуда не отправляет ничего о вас. Без аккаунтов, аналитики и отчётов о сбоях.

Приложение

  • Свободное место, размеры кэшей, список процессов и — только пока открыта панель и с вашего разрешения — названия вкладок браузера читаются на Mac и остаются на нём.
  • Настройки, история и логи хранятся в папке «Библиотеки» и удаляются вместе с приложением.
  • Единственный сетевой запрос: если вы разрешили, раз в день DiskPulse скачивает с GitHub два небольших публичных файла, чтобы узнать о новой версии, и саму версию — когда вы нажмёте «Обновить». В запросе нет идентификаторов и данных о вашем Mac; GitHub видит IP-адрес, как и любой сайт.

Этот сайт

Без cookies, трекеров, внешних шрифтов и скриптов. Выбранный язык запоминается только в вашем браузере. Файлы раздаёт GitHub Releases.

Полная техническая версия лежит рядом с исходным кодом: docs/PRIVACY.md.
