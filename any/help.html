Первый запуск.
First steps.

  1. Скачайте публичную сборку с главной страницы. Откройте DMG и перенесите any в Applications. / Download the public build, open the DMG and drag any to Applications.
  2. Запустите any из Applications. Приложение находится в строке меню и у выреза экрана. / Open any from Applications; find it in the menu bar and near the notch.
  3. Пройдите знакомство: выберите режим, подготовьте модели, разрешите микрофон, Input Monitoring и Accessibility. / Follow setup: choose a mode, prepare models, grant microphone, Input Monitoring and Accessibility.
  4. Проверьте речь в тренировочном поле, затем вставку в Notes. Настройте действие Globe/Fn на «Ничего не делать», если оно конфликтует с any. / Try the practice field and Notes. Set Globe/Fn to Do Nothing if it conflicts with any.
  5. Зажмите Fn, говорите и отпустите. Повторить знакомство можно через меню any. / Hold Fn, speak, release. Reopen the welcome tour from the any menu.

Модели / Models

Whisper — для речи. Qwen3-4B — отдельная загрузка для структуры и правки голосом. Для перевода нужны macOS 15+ и установленные языки Apple. Groq — необязательный облачный режим с вашим ключом.

Whisper handles speech. Qwen3-4B is a separate download for structure and voice edits. Translation needs macOS 15+ and installed Apple languages. Groq is an optional cloud mode with your own key.

Если что-то не работает / Troubleshooting

Проверьте разрешения и готовность выбранной модели в настройках any. Если Fn не заработал после выдачи доступа, используйте предложенный перезапуск. Если поле не поддерживает вставку, сохранённый результат можно скопировать из локальной истории.

Check permissions and the selected model in any settings. If Fn needs a relaunch after access is granted, use the offered relaunch. If a field does not support insertion, copy the saved result from local history.

Покупка / Purchase

Меню any → «Активировать лицензию…» → «Купить». В Telegram оплатите 385 Stars, скопируйте ключ и вставьте его в any. Ключ привязан к этому Mac; при повторном открытии покупки для оплаченного устройства бот выдаёт ключ снова.

any menu → Activate License → Buy. Pay 385 Stars in Telegram, copy the key and paste it into any. The key is bound to this Mac; reopening the purchase for the paid device retrieves its key.

Обновления / Updates

Меню any → «Проверить обновления». Перед переустановкой сохраните работу. История, ключи и модели находятся отдельно от приложения. Не стирайте Keychain ради повторного теста.

any menu → Check for Updates. Save your work before installation. History, keys and models are stored separately from the app. Do not erase Keychain to repeat a test.
