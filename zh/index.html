核心定位

为什么选择 Sverkaus？ 实验室单场景数据约在 ~50 条演示后进入平台期（arXiv:2410.18647），普通头戴 POV 视频缺乏手部接触与力反馈。Sverkaus 提供 Track A（视觉/双目/腕部同步）、Track B（3D 手部/动捕手套/触觉力传感/sEMG/可选 LWIR 热成像） 与 Track C（UMI/外骨骼/客户自带 BYO 硬件），通过现场 10–20 分钟校准测试 与 Edge QA（RELEASE/HOLD/REJECT），按“验收合格小时（Cost per Accepted Hour）”透明核算，并将真实失误与人工恢复轨迹完整保留。

02 · 常见问题

具身智能团队核心关注问题。

Sverkaus 与普通众包第一视角（POV）视频平台或实验室遥操有何本质区别？
普通众包视频缺乏同步腕部视角、相机标定与触觉力反馈；而实验室遥操难以部署到数十个真实商用后厨、洗衣房或车间。Sverkaus 按客户技术规格直接嵌入真实商业与工业班次，提供腕部同步+双目+3D手部追踪+UMI/触觉/sEMG/可选 LWIR 热成像（并支持客户自带 BYO 硬件），现场执行边缘质检（RELEASE/HOLD/REJECT），保留真实打滑与人工恢复轨迹，且绝不伪造机器人动作标签。
Sverkaus 支持哪些机器人数据导出格式与质量验证标准？
支持 LeRobot（Parquet + MP4）、RLDS、MCAP / Rerun、HDF5 / Zarr 及客户定制 Parquet + MP4 架构。每个交付批次均附带 JSON 溯源清单、SHA-256 片段校验和、相机内外参标定、跨流时间同步漂移指标（p95 Δt），并将录制时长、提交时长与验收合格时长严格分开核算。
中国或国际具身智能与人形机器人团队如何启动 Sverkaus 欧洲/乌克兰现场试点？
试点分三步推进：（1）技术规格对齐（锁定任务瓶颈、机器人构型、Track A/B/C 或 BYO 硬件、导出格式与验收门槛）；（2）场地安全审查（GO）与 10–20 分钟现场校准测试（验证手部可见性、同步漂移与格式导入）；（3）多场地真实班次批量交付并结合模型评测反馈进入迭代闭环。
