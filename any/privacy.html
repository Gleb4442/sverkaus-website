Локальные режимы / Local modes

Whisper и Apple Speech настроены для распознавания на устройстве без автоматического перехода в облако. Локальная текстовая модель обрабатывает запросы структуры и правки на Mac. Модели загружаются из внешних источников по явной команде. Перевод Apple требует поддерживаемых установленных языков.

Local speech and text modes process content on your Mac without an automatic cloud fallback. Model downloads contact external model hosts only when requested. Apple Translation requires supported installed languages.

Облачный выбор / Cloud choice

При выбранном Groq приложение отправляет аудио для распознавания и соответствующий текст для обработки в Groq с вашим ключом. Ключ хранится в macOS Keychain. Действуют условия выбранного сервиса.

Choosing Groq sends the relevant audio and text to Groq using your key, stored in macOS Keychain. The provider's terms apply.

История / History

История, словарь, настройки и резервное аудио хранятся на этом Mac. Управляйте сохранением и удалением в приложении. Автоматической синхронизации с аккаунтом any нет.

History, vocabulary, settings and audio backups live on this Mac. Manage retention and deletion in the app. There is no automatic any account sync.

Лицензия и обновления / Licence and updates

Trial использует хеш идентификатора Mac и локальную запись начала периода. При подключённом сервере trial хеш отправляется для проверки, попытки ограничены одним разом в сутки. Исходный аппаратный UUID не отправляется. Покупка проходит через Telegram; бот хранит сведения, необходимые для выдачи лицензии устройству. Проверка купленного ключа выполняется офлайн. Проверка обновлений обращается к каналу выпуска.

Trial checks use a hashed Mac identifier and local trial records; a configured trial server is checked at most daily. The raw hardware UUID is not sent. Telegram handles purchases, and the bot stores the information needed to issue the device licence. Purchased keys are validated offline. Update checks contact the release channel.
