Engineered for Developer Macs

Xcode builds, simulators, npm packages, and parallel AI coding agents quietly fill your storage until builds fail. DiskPulse watches free space, explains where it went, and cleans safely.

🔒

100% Local

No accounts, no analytics, no external trackers. Your filesystem data never leaves your Mac. The only network call is an optional, opt-in daily update check against GitHub.

🧹

Safe Background Autoclean

Runs quietly in the background every 5 minutes when disk space drops below safe thresholds. Strictly cleans caches from an allow-list; never deletes your source code or documents.

🧠

RAM & Swap Protection

Swap lives on the disk. Under memory pressure, DiskPulse frees disk space early and terminates orphan MCP and language servers whose parent process has died, preventing system freezes.

⚡️

PreToolUse Guard

Cleaning cannot outrun three parallel Xcode builds. The guard hook for Claude Code refuses builds, installs, and simulator boots when free space drops below 5 GB, protecting your drive.

🤖

Agent Resource Manager

Coordinates parallel coding agents (Claude Code, Codex). Heavy compiler and test tasks share a resource pool sized to your Mac so agents complete tasks without CPU and memory thrashing.

⬆️

Signed & Notarized

Signed with Apple Developer ID and notarized by Apple. Supports one-click updates verified by cryptographic signature before install. Fully open source under MIT.

What Gets Cleaned

DiskPulse only cleans files that are guaranteed to re-create themselves automatically, and only when they are not in use. Open applications are never touched.

Tier Files & Actions
● Always Safe Xcode Build Data of deleted projects and worktrees, old ModuleCache, PIFCache.
Tool Caches: npm, npx, VS Code, headless-Chrome, pip, uv caches when tools are not running.
Agent Temp: Completed Claude Code background tasks (2h after session ends).
Closed Apps: Hidden Electron caches in Application Support (Slack, Notion, Figma, Claude) — never Local Storage or cookies.
● With Consent Deep Clean («Глубже…»): Xcode builds for projects untouched for 7+ days; simulators for completed agent jobs; node_modules in idle agent worktrees.
Manual Consent Only: Installers & DMG archives in Downloads older than 30 days, iPhone backups older than 6 months, untouched AI models (Hugging Face / LM Studio).
✕ Never Touched Your Work: Documents, Desktop, Photos, Mail, Keychain credentials.
Git Repositories: Anything with uncommitted or unpushed work is strictly untouchable.
Running Programs: If an app is open, it is in use. DiskPulse never quits running apps. Active agent memories and config directories (~/.codex, ~/.gemini, ~/.cursor) are never touched.

Frequently Asked Questions

How does DiskPulse protect my open work?

DiskPulse checks whether an application is currently running before cleaning its caches. It also checks git status for uncommitted modifications. If a folder belongs to an open process or an active git worktree, it is bypassed completely.

Can it be run completely from the CLI without GUI?

Yes. DiskPulse uses a standalone standard Python engine (Engine/diskcare.py). You can run python3 Engine/diskcare.py audit to inspect usage, plan to preview deletions, or clean directly from any terminal or CI pipeline.

Where are my custom rules saved?

You can create ~/Library/Application Support/diskcare/config.json to specify folders that must never be touched, simulator prefixes, and notification thresholds. Everything stays strictly local on your Mac.
